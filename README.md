# EFFORT ダウンロード

1対1で撃ち合う、Windows 用のゲーム「EFFORT」の置き場です。

## ダウンロード

**[EffortSetup.exe をダウンロード](https://github.com/yushi-777/effort-download/releases/latest/download/EffortSetup.exe)**（インストーラー。約 75MB）

## 始め方

1. ダウンロードした `EffortSetup.exe` を開く
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を選ぶ
3. 「次へ」→「インストール」→「完了」と進む
4. デスクトップかスタートメニューの「EFFORT」から起動する

やめるときは、Windows の「設定」→「アプリ」→「インストールされているアプリ」から「EFFORT」をアンインストールします。

## 更新について

ゲームは、起動するたびに新しい版があるかを確かめて、自分で更新します。ダウンロードし直す必要はありません。

## インストーラーを使わないとき（ZIP）

インストールせずに、フォルダーのまま置きたい人向けです。中身は同じです。

**[Effort-client.zip をダウンロード](https://github.com/yushi-777/effort-download/releases/latest/download/Effort-client.zip)**（約 100MB）

1. ダウンロードした `Effort-client.zip` を右クリックして「すべて展開」を選ぶ
2. できた `Effort` フォルダーの中の `Effort.exe` を開く
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を選ぶ
